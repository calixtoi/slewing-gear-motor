Slewing Drive Motor Dimensioning Tool

Universal Motor Sizing for PM010 & PM401 Crane Lines

SAP Designation: PM010 (PF-Redesign: PF120, PF160, PF200) and PM401

Tool Purpose

This tool sizes a single motor to meet the electrical requirements of all PM010 crane variants (PF120, PF160, PF200) and the PM401 crane type.

Key Concept: Rather than carry the full peak structural load, the motor is designed to deliver a conservative 30% minimum share. This approach is validated by proven PF200 historical performance (35% historical share) and ensures robust operation across all variants while maintaining cost-effectiveness.

Sizing Basis: The Substation operation scenario on PM401 (62 kNm peak torque) represents the worst-case requirement across all variants, making it the governing dimensioning constraint.

Slewing Ring: Fixed 110:1 gear ratio with 40% mechanical efficiency — a shared mechanical component across all variants.

About This Tool

Slewing Motor Selector is a comprehensive Django web application for digitising the engineering workbook used to size and verify slewing drive motors for industrial cranes.

The tool implements six interconnected modules:

  1. Cover — Design basis and editable source parameters
  2. Motor Cycle Calculation — Full sizing calculation from torque to power
  3. Ideal Motor Parameters — Complete specification requirements
  4. Motor Verification — Supplier datasheet comparison
  5. Formula Library — All formulas explained in plain English
  6. Settings — Design parameter configuration (accessible via Cover page)

All calculations are performed dynamically from editable design parameters stored in a shared SQLite database. Changes to source parameters instantly propagate across all calculations and verification results.
