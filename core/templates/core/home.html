About This Tool

Slewing Motor Selector is a comprehensive Django web application for digitising the engineering workbook used to size and verify slewing drive motors for industrial cranes.

The tool implements six interconnected modules:

  1. Cover — Design basis and editable source parameters
  2. Motor Cycle Calculation — Full sizing calculation from torque to power
  3. Ideal Motor Parameters — Complete specification requirements
  4. Motor Verification — Supplier datasheet comparison
  5. Formula Library — All formulas explained in plain English
  6. Settings — Design parameter configuration (accessible via Cover page)

All calculations are performed dynamically from editable design parameters stored in a shared SQLite database. Changes to source parameters instantly propagate across all calculations and verification results.
