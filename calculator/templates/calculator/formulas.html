Combined Factor
Combined factor — total torque multiplication from GM output to ring
$$CF = i_{\text{slew}} \times \eta_{\text{slew}}$$
islew = Slewing-ring reduction ratio (:1) PF Std: 121 | PF-XXL: 110
ηslew = Slewing-ring efficiency (–) Both: 0.40
CF = Combined factor (–) PF Std: 48.4 | PF-XXL: 44.0
Speed Calculations
Total reduction ratio
$$i_{\text{tot}} = i_{\text{gb}} \times i_{\text{slew}}$$
igb = Gearbox reduction ratio (:1) — motor input
islew = Slewing-ring reduction ratio (:1) — system constant
GM output speed
$$n_{\text{gm}} = \frac{n_{\text{mot}}}{i_{\text{gb}}}$$
nmot = Motor rated speed (rpm) — from datasheet
Crane slewing speed
$$n_{\text{slew}} = \frac{n_{\text{gm}}}{i_{\text{slew}}} = \frac{n_{\text{mot}}}{i_{\text{tot}}}$$
nslew = Critical for system design and operation
Power Consistency Check
Power consistency deviation — Limit: ΔP ≤ 5%
$$\Delta P = \frac{\left| P - \frac{T_{\text{nom}} \times n_{\text{gm}}}{k} \right|}{P} \times 100\%$$
P = Motor rated power (kW) — from datasheet
Tnom = GM nominal torque (Nm) — from datasheet
k = Torque constant = 60000/(2π) = 9549.3
Checks if declared power matches torque×speed product
Ring Torques (GM Output → Ring)

All GM-output torques are multiplied by CF to get ring-level torques:

Ring running/nominal torque
$$M_{S2} = T_{\text{nom}} \times CF$$
Ring pull-up torque — Limit: MPU ≥ 0.9 × Mrated
$$M_{\text{PU}} = T_{\text{pu}} \times CF$$
Tpu may be missing in datasheet → REVIEW status
Ring start/breakaway torque — Limit: Mrated ≤ Mstart ≤ Mmax
$$M_{\text{start}} = T_{\text{start}} \times CF$$
Critical check: must be within structural band
Ring peak torque — Limit: Mpeak ≤ Mmax
$$M_{\text{peak}} = T_{\text{peak}} \times CF$$
Derived Limits (Reverse Calculations)
Required GM nominal torque
$$T_{\text{gm,nom,req}} = \frac{M_{\text{rated}}}{CF}$$
PF Standard: Tgm,nom,req = 15360 / 48.4 = 317.4 Nm
PF-XXL: Tgm,nom,req = 65000 / 44.0 = 1477.3 Nm
Maximum permissible GM starting torque
$$T_{\text{gm,start,max}} = \frac{M_{\text{max}}}{CF}$$
PF Standard: Tgm,start,max = 41190 / 48.4 = 851.0 Nm
PF-XXL: Tgm,start,max = 70000 / 44.0 = 1590.9 Nm
